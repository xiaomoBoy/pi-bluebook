# 实操案例

这里不重复讲一遍概念。每个案例都归属于一个蓝皮书模块，从一份明确材料开始，写清任务、限制、预期结果和失败后的恢复方式，让读者可以在自己的环境里完整复现。

## 案例结构

每个正式案例都应包含：

1. 可以下载或自行准备的练习材料；
2. 一段可以直接交给 Pi 的任务说明；
3. 执行过程中应该看到的关键现象；
4. 不依赖 Agent 自述的验收方法；
5. 出错后保留现场和恢复的方法。
