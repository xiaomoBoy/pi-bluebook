<h2 id="learning-path">从零开始的五个阶段</h2>

| 阶段 | 你会完成什么 | 学习结果 |
| --- | --- | --- |
| [01 安装与基础设置](/guide/before-install) | 认识终端，检查 Node.js，安装 Pi，连接模型 | 能在独立练习目录启动 Pi |
| [02 完成真实任务](/guide/first-task) | 整理会议记录，学会文件引用、会话续写和独立验收 | 知道“Agent 说完成了”不等于完成 |
| [03 长任务与上下文](/guide/context-and-compaction) | 理解压缩、提示缓存和可持续产物 | 能处理越来越长的任务 |
| [04 扩展自己的 Pi](/guide/skills-extensions-packages) | 区分 Skill、Extension 和 Package，理解子 Agent 分工 | 把重复经验变成可复用能力 |
| [05 稳定工作流](/guide/vps-and-long-running) | 理解权限、隔离、VPS 和长任务验收 | 搭出适合自己的可控工作流 |

## 两条辅助线
