## 阅读凡例

### 1. 主线以 macOS 为准，Windows 走独立入口

主线截图、快捷键和常用目录以 macOS 为基准。Windows 用户先阅读[Windows 中文路径](/guide/windows-setup)，在 Git Bash 中完成安装与首次启动，再接回第 3 课。Linux 读者可使用 macOS/Linux 通用命令，并自行替换主目录路径。

### 2. 动态事实看页内日期

模型名称、Provider、登录方式、命令参数、价格、额度和第三方项目状态都会变化。涉及这些内容时，应同时查看页面的最后更新日期，并以 [Pi 官方文档](https://pi.dev/docs/latest)及对应服务商的当前说明为准。

本书不维护模型价格表或插件排行榜。过期的具体数字会校订或标注日期，但不会把短期促销提升为长期建议。

### 3. 截图帮助定位，不替代操作步骤

截图用于确认界面区域、状态和成功信号。界面更新后，按钮位置和文字可能变化；读者应按正文中的目标、步骤与验收继续判断，而不是只寻找一张完全相同的画面。

涉及系统级结果时必须使用对应证据。例如，终端里打印通知文字，不等于桌面通知已经出现；没有真实系统截图和复现场景的功能，会明确标为未验收或进阶内容。

### 4. 命令块默认需要逐行理解

命令中的目录名、文件名和示例值只适用于相应练习。粘贴前先确认当前目录，不把真实 API Key、主密码、私人路径或生产凭据写进提示、截图和仓库。

破坏性操作不会因为出现在教程里就自动安全。遇到与自己环境不一致的路径，先停止并核对目标。

### 5. “完成”必须有外部证据

每一课给出完成标志或验收步骤。Agent 的自我总结、浏览器里的成功提示、终端的一行输出，都只代表部分信号；最终应检查文件、内容、测试、远端状态或真实界面。

## 网站与固定版怎样维护

- **网站可以持续校订：** 修正错字、失效链接、已变化的命令和核验日期；补充不会改变学习结构的说明。
- **本版结构保持稳定：** 导论、序章、五个模块、案例、插件推荐、授权译文和附录构成 2026 开放学习版的基本目录。
- **重大变化另起版次：** 如果 Pi 的安装、核心概念或学习路径发生结构性变化，应更新版次说明，而不是悄悄改写旧版主张。
- **PDF 使用明确快照：** 后续发布的 PDF 将标出生成日期、内容核验截止和对应提交，方便下载、打印和引用。
