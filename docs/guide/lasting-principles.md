# 从 98 条推文留下的十条判断

98 条推文记录的是一个持续学习的过程。里面既有后来保留的判断，也有被后续实践修正的猜测、当时有效的价格与短期产品状态。

本页不重写推文，也不把个人体验直接包装成官方结论。它只收录在多次实践中反复出现、与本书当前课程一致、截至本版核验时仍可作为学习原则的十条判断。想看形成过程，可以回到[推文学习目录](/tweets/)阅读原文。

## 1. 新手最大的障碍往往是使用成本，不是概念

理解 Agent、Session 或 Context 需要时间，但真正阻止许多人继续练习的，常常是没有可用的模型访问方式，或无法判断一次任务会消耗多少额度。开始前先弄清订阅登录、API Key、余额和限额，比先比较模型排行榜更实际。

**落到课程里：** [第 3 课](/guide/connect-model)先完成一种可用认证和一次无文件调用；正式任务从小材料开始。

## 2. Pi 的价值不是功能最多，而是底座足够小

Pi 把模型、工具、Session 和上下文连接起来，核心保持克制，更多能力按需扩展。这不是“尚未做完”，而是一种把工作流决定权交还给使用者的设计。

**落到课程里：** 先学默认能力，再[区分 Skill、Extension 与 Package](/guide/skills-extensions-packages)，不用功能数量评价 Harness。

## 3. 先装全家桶，会失去对因果的判断

同时加入多个插件后，一项能力究竟来自核心、模型还是某个扩展，常常说不清；出错时也难以定位冲突。新手更需要一个可解释的环境，而不是一个看起来无所不能的环境。

**落到课程里：** 保持最小配置，出现真实需求后一次只试一个插件；启用前后都留下可观察结果。

## 4. Skill 应从重复工作里长出来

收藏别人的 Skill 不等于建立自己的工作流。更可靠的做法，是先完成几次真实任务，找出反复出现的审阅、整理或发布步骤，再把已经稳定的方法写成 Skill。

**落到课程里：** 第一个 Skill 从已有行动清单中提炼规则，而不是先浏览市场凑数量。

## 5. 一件事使用一条 Session

登录、写文章、改代码和随手问答都挤在同一条 Session，模型会面对互不相关的历史。方向已经混乱时，继续解释或等待压缩，往往只会把混乱保留下来。

**落到课程里：** [为任务建立可搜索的独立 Session](/guide/sessions)；走偏时回到分叉点，或及时开启新会话。

## 6. Session 可保存，不等于模型始终记得全部内容 {#session-and-context}

Session 保存的是可继续处理的历史结构；模型每一轮看到的 Context 只是从中构造出来的一部分。完整历史仍在文件里，并不保证每个旧细节一直位于当前上下文窗口。

**落到课程里：** 把真正不能丢的目标、约束、决定和下一步写进检查点文件，不把长期任务只寄托在聊天记忆上。

## 7. 压缩与提示缓存必须分开理解 {#compaction-and-cache}

压缩是为了在上下文接近上限时用摘要替代部分旧历史；提示缓存是服务商对稳定前缀的复用与计费机制。一次压缩可能改变前缀并降低当时的缓存命中，但两者不是同一个功能，也不能用缓存数字判断任务质量。

**落到课程里：** 模块三分别学习[压缩](/guide/context-and-compaction)和[提示缓存](/guide/prompt-caching)，验收仍回到文件、约束与最终产物。

## 8. 子 Agent 首先是分工方法，不是一个内置按钮

Pi 默认不把子 Agent 固化进核心。真正重要的是能否把搜索、整理、执行和复核拆成边界清晰的任务，并说明每一份结果怎样交回。没有这种能力，增加 Agent 数量只会放大成本和沟通损耗。

**落到课程里：** [先用两个独立会话练习分工和交接](/guide/subagents)，再决定是否安装多 Agent 扩展。

## 9. 提示词规定范围，操作系统决定权限

“只改这个目录”能够帮助模型理解任务边界，却不是技术隔离。Pi 的工具和 Extension 以当前进程拥有的权限运行；面对不可信代码和材料时，需要容器、虚拟机或专用账户等真正的隔离措施。

**落到课程里：** [Project Trust 不当作沙箱](/guide/safety)，敏感凭据不进入提示、截图或仓库，危险操作由外部环境限制。

## 10. 完成声明不能替代独立验收

Agent 说“已经完成”，只代表它做出了判断。文件是否存在、内容是否完整、命令是否成功、线上版本是否更新，必须使用不依赖该声明的证据检查。

**落到课程里：** 每一课都设置可见的完成标志；重要修改要读取产物、运行检查并核对最终状态。

## 档案和蓝皮书的分界

推文继续保留发布日期、原始表达和认识变化，不因为本页出现而回写。涉及具体模型、价格、免费期、插件状态和短期推荐的内容，也不会提升为长期结论。

本页的十条判断会随着正式版次审阅；网站可以补充证据或纠正表述，但不会追着每一次生态变化扩张成排行榜。
