# 会话的保存与续写

做完第一个任务后，很多人会问：关闭终端以后，刚才的对话是不是没有了？

Pi 默认会自动保存会话，并按工作目录组织。你无需每说一句就手动保存，但需要学会给会话起名字，否则日后会很难找回来。

## 一件事对应一个会话

一个实用的起点规则是：一个明确目标，使用一个会话。整理会议记录、修复网站导航和翻译一篇文章，最好不要全部塞进同一条对话。

任务开始后，在 Pi 输入区输入：

```text
/name 会议记录整理练习
```

名字应该描述任务，而不是写“测试 1”或“今天的对话”。一周后回来，你仍然能从名字判断内容。

输入完按 `Return`。再输入 `/session` 并按 `Return`，当前会话信息中出现“会议记录整理练习”，这一步才算完成。

## 关闭以后继续做

如果你刚退出 Pi，而且要继续当前目录最近的会话，先在普通终端回到练习目录：

```bash
cd ~/Downloads/pi-practice
pwd
pi -c
```

`pwd` 必须显示正确的练习目录。`pi -c` 打开后，用 `/session` 检查名字，应该仍然是刚才的“会议记录整理练习”。

如果这个项目有多个会话，使用：

```bash
cd ~/Downloads/pi-practice
pwd
pi -r
```

这会打开历史会话选择器。用上下方向键找到对应名称，按 `Return` 打开，按 `Esc` 取消。也可以在已打开的 Pi 中输入 `/resume`。选择前先看会话名和工作目录，别把相似项目接错。

如果你使用的练习目录名不是 `pi-practice`，把两处 `cd` 命令里的目录名一起替换掉。

::: tip 你现在只要记住两个入口
`pi -c` 续写最近会话，`pi -r` 从列表中选择。其他选项可以等真正遇到需求再学。
:::

## 走错方向时用 `/tree`

对话不是只能一路向下。Pi 的会话以树状结构保存。在交互界面输入 `/tree`，可以回到之前的某个节点，然后从那里继续。本课先把它作为进阶入口，不要在重要会话中随意跳转。

适合使用的场景包括：

- 你发现三轮之前就理解错了任务。
- 想保留当前方案，同时尝试另一条路。
- 对话已经被临时调试信息占满，想从比较干净的节点重新开始。

跳转不会把已经写入磁盘的文件恢复到早期状态。会话树管理对话历史，Git 或备份才管理文件版本。

## 新任务就新建会话

当目标已经变了，在 Pi 中输入 `/new`。之前的会话仍然保留，新任务会获得一个干净起点。

离开本章前，做一次小练习：给当前会话命名，用 `/session` 看到名字，用 `/quit` 退出，回到正确目录后再用 `pi -c` 回来。重新打开后还能看到同一名字和先前消息，这一课才算通过。
