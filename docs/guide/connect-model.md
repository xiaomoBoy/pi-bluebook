# 登录账号，让 Pi 能回答你

Pi 提供交互界面和文件工具，真正生成回复的是你选择的模型服务。所以安装完 Pi 后，还需要连接一个你已经可以使用的服务。

开始前，你需要已经拥有一种可用凭据：官方当前支持的订阅登录，或对应模型服务已启用的 API Key。只有聊天产品账号、不含 API 使用额度的账号，未必能在 Pi 中调用模型。订阅登录可能打开浏览器；API Key 路线可能产生模型服务商费用，先确认自己的账户和计费状态。

::: info Windows 用户
如果你刚完成 [Windows 中文安装路径](/guide/windows-setup)，本课和后续课程中的“普通终端”都指 Git Bash。下面的 `~/Downloads/pi-practice` 请换成你已建立的 `~/pi-practice`；Pi 编辑区里的 `/login`、`/model` 等命令不变。
:::

## 1. 选择一种登录方式

如果你上一课后已经退出 Pi，先在终端重新进入练习目录。

```bash
cd ~/Downloads/pi-practice
pwd
pi
```

如果你在第 1 课使用了其他练习目录名，先把命令中的 `pi-practice` 替换掉。确认 `pwd` 以你实际的练习目录名结尾。进入 Pi 后输入：

```text
/login
```

这条 `/login` 要输入在 **Pi 底部的编辑区**，不是退回普通终端后输入。输入完按 `Return`。菜单出现后，用上下方向键移动选中项，按 `Return` 确认，按 `Esc` 返回上一层或取消。

![Pi 中打开的真实登录方式选择菜单](/images/02-Pi-登录方式-实操图.png)

截图停在选择入口，没有继续提交账号或凭据。蓝色箭头表示当前选中项；你可以在账号登录与 API Key 两条路线之间移动。任何真实 Key、验证码和账号信息都不应进入教程截图。

按界面提示选择一条路线。

- 已有受支持的订阅，选择对应服务，按浏览器授权流程完成登录。
- 已有 API Key，选择对应服务，只在 Pi 本机登录界面中输入。

如果任何步骤要求把 Key 写进项目文件、聊天输入区、截图或普通终端命令历史，按 `Esc` 取消，不继续粘贴。本课只接受 Pi 的本机认证入口或官方明确说明的环境配置方式。

某些登录方式会自动打开浏览器。在浏览器中确认完成后，回到原来的终端窗口。终端中重新出现 Pi 的输入区，才表示登录流程已经返回。不要因为浏览器显示“成功”就关闭整个终端。

官方当前支持的订阅和提供商会变化，请以 [Pi Providers](https://pi.dev/docs/latest/providers) 为准。某个聊天产品账号存在，不代表它一定包含 Pi 所需的模型访问权限。

::: danger 不要公开凭据
不要把真实 API Key 贴进聊天、教程、截图或 GitHub 仓库。如果怀疑密钥已泄露，立即到服务商后台撤销旧密钥并创建新密钥。
:::

## 2. 选择当前账号可用的模型

登录返回 Pi 后，输入：

```text
/model
```

用上下方向键移动，按 `Return` 选中模型。列表关闭并回到编辑区后，查看底部状态栏，确认当前模型名已经显示。

![Pi 中打开的真实模型选择器](/images/03-Pi-模型选择-实操图.png)

选择器只显示当前已配置 Provider 可用的模型。截图中的列表会随账号和时间变化；绿色勾与蓝色箭头帮助确认当前项，选中后仍要回到底部状态栏复核模型名。

如果希望下次启动继续使用它，在模型选择器中按 `Ctrl+S` 保存为启动默认值。不要把教程中的某个模型名称当成唯一正确答案，模型的名称、可用性和计费都会变化。

## 3. 做一次无文件操作的连通测试

回到编辑区，提交这句话：

```text
只回复“Pi 已连接”。不要读取、创建、修改文件，也不要运行命令。
```

粘贴到 Pi 底部编辑区后按 `Return`。界面可能会先显示正在思考或等待网络，这时不要重复提交。等到模型真正返回文字，并且底部编辑区再次可输入，才是这轮结束。

看到完整的“Pi 已连接”回复才算通过。泛泛的欢迎语、只看到“登录成功”提示，都不能证明当前模型完成了这次真实调用。

如果 Pi 准备读写文件或运行命令，按 `Esc` 中止。这次测试不需要任何工具。

::: warning 没有收到回复
- 看不到可用模型，先回到 `/login` 检查认证。
- 选完模型但状态栏没有变化，先取消当前操作，重新打开 `/model` 核对；不要连续切换多个提供商。
- 测试请求长时间不返回，先按 `Esc` 停止这一轮，保留状态栏模型名和错误文字，再检查网络与该服务状态。
- 出现 `unauthorized`、余额或额度错误，保留原始文字，检查当前账号权限。
- 浏览器授权后没有回到 Pi，取消本次登录，确认浏览器中的账号后再重试。
- 不知道错误在哪里，从第一行错误到底部输入区整段复制，但要先遮住 API Key、邮箱和私人路径。
:::

## 本课验收

- `/login` 完成了一种可用的认证。
- 底部状态栏显示当前模型。
- 测试准确回复“Pi 已连接”，且没有工具调用。
