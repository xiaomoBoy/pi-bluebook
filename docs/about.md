# 关于作者

我是小墨，一名独立开发者，也是 [Pi 学习蓝皮书](/) 的整理者。我平时做 Agent 相关的实践、写作与开源工具，也参与 [AI Spark](https://aisparkedu.com/) 的工作。

## 为什么写这本书

最初只是好奇：一个看起来很简洁的 Pi，为什么能成为许多工作流的起点？我从自己动手做第一个任务开始，留下学习记录，后来读源码、试着写 Extension，也不断修正早先的判断。

记录越多，越觉得新手需要的不只是一份功能清单，而是一条能从第一次任务走到自己搭建工作流、每一步都知道怎样检查结果的路线。这就是蓝皮书的来由。仍在变化的个人想法和试错，留在[小墨札记](/journey/)；经过重新核验、适合照着操作的内容，才放进主线。

## 我怎样判断一件事做成了

比起 Agent 说自己做完了，我更关心结果能不能跑通、复现，并由自己验收。所以这里尽量按“场景 → 概念 → 实操 → 验收”来写；发现旧判断不准确，也会回头改。
