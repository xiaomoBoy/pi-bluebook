# 代理框架（Agent Harness）千千萬，這一個屬於我

*一個非工程師的筆記*

我不是工程師。在一家為那些對著黑色終端機視窗敲字的程式設計師開發代理框架軟體的公司裡，這件事以前讓我覺得應該小聲說出來。身邊每個人都在交付程式碼，我則在寫文件、做規劃、與人交談。這些工作當然有用，但我並沒有真正使用我們製造的東西。

於是有一段時間，我像許多人面對 AI 時悄悄做的那樣：跟著點頭。我聽過“Agent”“迴圈”“代理框架”和“擴充功能（Extension）”足夠多次，已經能夠在會議裡很像樣地點頭。別人都覺得 TUI 是常識時，我卻在偷偷搜尋它是什麼；等我終於弄懂，大家早已談起 API，我又回到了起點。借用我們《[什麼是代理框架？](/zh-TW/translations/what-is-a-harness)》中的一句話，我就是那個“因為不好意思而沒有問出口”的人。

後來，我不再只是點頭，而是做了一件更好的事：開啟 Pi，開始提問。

代理框架並不在意你不會程式設計。開啟它，用自然語言寫下想要什麼，它就開始工作。我原以為總會碰到一個關卡，因為自己懂得不夠而卡住。但實際情況是，我只需要繼續寫下自己的需求。第一次讓它閱讀一份又長又難看的 PDF，並告訴我真正需要知道的三件事時，它就那麼完成了。我感到一陣小小的、甚至有點滑稽的力量湧上來。

在令人望而生畏的外表之下，代理框架只是一種工具：把“我希望有人能替我做這件事”，變成“已經完成”。

## 把它變成我的

Pi 最讓我喜歡的用途與軟體開發毫無關係。每天早晨，它會讀一遍我的收件箱和會議記錄，找出我真正答應別人要做的事情，然後生成一份乾淨的待辦清單：一組是我欠別人的，另一組是我正在等待別人回覆的。

我沒有僱人，也沒有先去學程式設計。我只描述了一次這份工作，它就變成在我電腦上執行的小流程，而且完全按照我的思維方式塑造。

偶爾好奇心上來、想開啟引擎蓋看看時，Pi 又是一位非常耐心的老師。有一次，我讓它指導我編寫 Google Apps Script。它一步一步帶我走完整個過程，就像請一位最慷慨的軟體工程師同事來講解：使用平實的語言，而且不會讓你覺得自己很笨。

在某次解釋進行到一半時，程式碼不再那麼令人害怕。現在，我也會自己製作東西了。它們並不驚天動地，主要是一些真正能讓工作和生活輕鬆一點的小工具：製作個性化數字邀請函、管理郵件互動指標，以及用電子表格自動化整理資料。

也就是在這時，那句標語終於對我有了意義：代理框架千千萬，但這一個是你的。

過去，我把它理解成寫給工程師的話——寫給那些會開啟引擎蓋、重新接線的人。現在我對“你的”有了不同理解。它不是說這個工具一定由你親手創造，而是說，無論你是誰，都可以讓它適應自己的生活。

我讓自己的 Pi 圍繞雜亂的收件箱運轉。另一個人也許會讓它圍繞課程規劃、研究或小企業記帳運轉。

## 為什麼這件事比我的待辦清單更重要

Pi 免費、開源，而且執行在我自己的膝上型電腦上。過去，這聽起來只是一個技術腳註。現在我明白它為什麼重要：我可以按照自己的工作方式塑造它。

真正讓我感到不同的是，Pi 能檢視自己的程式碼，解釋它如何工作，再幫助我修改它。彷彿這個工具能夠教我怎樣重新打造工具本身。原文寫作時，Pi 使用者已經相互分享了 5,000 多個擴充功能，把自己構建的工作流自由地交給其他人。

關於 AI 的許多討論，都集中在這項技術會對我們做什麼。坐在我的位置上，真正有意思的變化是：我不再需要等待某個技術人員替我做出想要的工具。

我仍然不是工程師，但已經不會壓低聲音說這件事了。原來，擁有自己的工具並不要求你先成為工程師；你只需要有足夠的好奇心去提問，也有足夠的勇氣繼續走下去。

——Jakob，Earendil Founders Associate
