# 制高點

## 引言

這份備忘錄試圖回答一個問題：在 2026 至 2031 年間，基礎模型提供商之外的軟體和計算領域，“制高點”會出現在哪裡？

背景是 AI 的迅速普及：它一方面不斷進入更廣泛的消費者和企業軟體場景，另一方面也越來越多地被用於編寫軟體。

## 消費者與企業軟體中的 AI

預測 AI 會繼續滲透軟體，並不需要承擔多大風險。與現狀相比，這會催生四項主要變化：

1. **通用系統會以高度專業化系統的萎縮為代價不斷增長。** 這源自所有主要 LLM 都具備的通用理解能力。
2. **軟體系統可以透過自然語言控制和定製。**
3. **軟體能夠獲得自我感知能力。** 把程式碼和使用者行為輸入 LLM，會產生一種近乎湧現的能力，形成能夠感知自身的軟體。
4. **上下文在高度通用的系統中佔據首要地位。** 專業化不再源自軟體預先確定的架構，而是來自執行或推理時，對最相關使用者與業務上下文的廣泛獲取和審慎運用。

## 軟體創造中的 AI

同樣清楚的是，AI 正在顯著改變軟體的編寫方式。我們也可以從四個維度描述這種變化：

1. **創造軟體的成本會下降。** 世界上會出現更多軟體。
2. **編寫軟體的人會改變。** 進入門檻正在降低。缺乏通用技術能力、卻擁有專業知識和判斷品位的人，也能駕馭具備通用能力的模型。
3. **由 LLM 編寫的軟體將成為中位數，也就是平庸的軟體。** 真正能在細分領域勝出的優秀公司，要麼由對高效、可擴充系統工程有獨到見解的軟體架構師引領，要麼由兼具獨特市場洞察與品位的工匠，駕馭 LLM 的通用能力來打造。
4. **AI 正在提高參與率。** 這既體現在誰能夠編寫軟體，也體現在終端機使用者怎樣按照自己的偏好改造軟體。因此，最好的系統應當開放、可適應，允許更廣泛的開發者社群參與貢獻，同時也讓終端機使用者擁有高度定製能力。

## 關於社交媒體的一點說明

即使機器還沒有大規模進入社交媒體，人們對社交媒體的總體滿意度也已經明顯偏低。這些平台彼此割裂，所有權卻越來越集中在少數人手中。演算法把使用者推向刺激與渴望不斷迴圈的內容。

當你聽餐廳和酒吧裡的談話時，毫不誇張地說，人們經常帶著厭惡和自我責備談論自己使用社交媒體的方式。我們不願讓孩子接觸它，它也沒有豐富我們的生活或人際關係。

當然，仍有少數社群從社交媒體中得到的好處多於傷害：那些因一門手藝、共同熱情或興趣而聚集起來的人。但這些真正有價值的角落，大多只是沙漠中的綠洲。

人類之間有意義的數字互動，主要仍存在於私密空間，例如即時通訊、聊天、小部分論壇和電子郵件通訊。

## 制高點

制高點將出現在這樣一個交匯處：人與人彼此互動，同時也與能力卓越、可定製、個性化、令人愉悅、簡單易用，並且能夠保有使用者信賴的系統互動。下面逐項拆解這些特徵。

### 互動

正如量子物理學家所知，宇宙更多地從事物之間怎樣互動中湧現，而不是從事物本身是什麼中湧現。當機器逐漸擁有理解人類自然語言的能力，我們會更希望讓資訊在互動中形成和流動，而不是建立並維護靜態的資訊結構。

### 能力

這意味著擁有最先進的 Agent 能力，同時保持精確，避免重大錯誤。

### 可定製

這意味著終端機使用者——無論個人、小企業還是公司——都能按照自身偏好，在最大程度上修改系統，並且可以輕鬆、直觀地完成修改。

### 個性化

它超越可定製，儘管一部分個性化正是從定製中生長出來的。它意味著一個系統會逐步讓終端機使用者感覺到：這個系統**屬於自己**。它已經適應使用者獨特的生活背景和性格。

### 愉悅

系統本身會給終端機使用者帶來驚喜和快樂。人與它互動時，能夠感到一種驚奇與輕盈。

### 簡單

開始使用軟體以及繼續與它互動，都不復雜。

### 贏得並保有信賴

產品及其背後的公司應當以可信的方式呈現自己；透明地使用使用者上下文；不濫用使用者信賴，也不讓使用者暴露在無法接受的安全風險中。

透過實現以上特徵佔據制高點，意味著能夠解鎖“使用”和“上下文”之間至關重要的正向迴圈：

> 使用越多，積累的上下文越深；上下文越深，系統行為越精確；系統表現得越精確——尤其是相對於同類或競爭者——使用者就越願意繼續使用。

我們認為，只要系統能夠保有上述品質，就應該儘可能歸使用者所有。

## 最後的思考

最後，讓我們換一種方式理解這件事。

想象一座花園。讓自己在腦海中置身其中。你選擇種植什麼，也悉心照料它。花園也許有籬笆，使它與別人的花園和空間有所區別。這裡是一處安全空間，卻沒有與世界完全隔絕。天氣、氣候和外部世界仍會給你帶來限制。

隨著時間推移，花園會呈現出你怎樣回應這些限制，也反映你多年來作出的決定。久而久之，花園會映照出你的樣子。

你的花園裡生活著一個實體。它紮根於花園，卻又聰明、通曉世界、能力出眾。它主要為了引導和幫助你而存在，也能與其他人互動。它深刻了解花園裡的每一寸土地、每一朵初綻的花、每一枚果實，同時又能把花園裡的一切與廣闊的外部世界聯絡起來。

就像花園一樣，這個實體也會逐漸映照出你。你可以把它派往花園之外；即使如此，它仍帶著你在這片土壤中作出的選擇所賦予的色彩，也始終紮根於此。

Earendil 正在建造這個實體，也在建造這座花園。我們的系統從兩者之中湧現。

我們稱它為 Lefos。
