# 關於今日公告的一些思考

不到一年前，在春日的維也納，Armin 和 Colin 相約在 *Vogel Kaffee* 寫作。那時，我們已經確定了一個名字——*Earendil*，但還沒有公司，也沒有辦公室。我們正站在起點，覺得最自然的開端，就是共同寫下公司應該為何存在。

我們反覆修改那些句子，對每一個詞加以推敲和追問，最後寫成了這樣一句話：

*Earendil 的存在，是為了透過打造軟體和開放協議，彌合分歧與無知，培養持久的喜悅與理解，從而增強人類的自主權。*

這是一組遠大的目標，但我們認真對待其中每一個具體部分。在一個每天似乎都更加分裂和暴力的世界裡，這些詞既鮮明，又具有普遍意義；在一個每天似乎都更加恐懼的世界裡，它們既堅定，又平和。這正是我們的本意。

時間來到今天，我們很自豪地釋出三項訊息：第一，*Earendil* 已收購 [Pi](https://pi.dev)，Mario Zechner 也已加入 *Earendil*；第二，我們釋出 [Lefos](https://lefos.com)，一種以同時具備能力和可信度為目標的新型實體；第三，我們希望向早期支持者表達感謝。

在創辦 Earendil 之前，我們兩個人都在上一份工作中待了近十年。我們相信要[種下樹木](https://lucumr.pocoo.org/2026/3/20/some-things-just-take-time/)，再用時間照料它們。今天的三項公告雖然方式各不相同，卻都體現了這一原則。

首先是 Mario。Armin 從 Mario 還在讀大學時就已經認識他。多年來，Mario 一直透過編寫軟體打磨自己的手藝。Pi 的誕生以及後來被 Earendil 接納，一邊來自長期專注於磨鍊工藝，另一邊來自兩個人之間經年累月建立的信賴。

Pi 身處 AI 最熾熱的中心，同時又是手工打磨軟體的傑出範例。很難想象還有什麼能比它更貼合 Earendil 的核心原則。

其次是 *Lefos*。Lefos 真正起源於這樣一個問題：

*機器實體怎樣才能贏得人的信賴？它應當怎樣構建，才能讓這種信賴在數年乃至數十年裡不斷積累，而不是逐漸消耗？*

如今機器所展現的力量無可否認。但若要真正服務人類，我們認為必須重新思考幾項核心原則。

第一，這些機器應當以開放方式、建立在開放協議之上。第二，人們應當能夠按照自己的偏好和約束調整這些實體。最後，公司不應該理所當然地索取使用者信賴。

如果你曾有幸與一名助理共事，大概不會在對方上班第一天就交出自己所有電子郵箱密碼。信賴需要隨著時間贏得。我們的原則與此類似：我們希望 Lefos 能夠逐漸向你證明，它值得信賴。我們期待它做到這一點，也期待聽到你的回饋。

最後是我們的支持者。從創立之初，Earendil 就得到了 Accel（Daniel Levine）、Balderton（Daniel Waterhouse），以及 n8n（Jan Oberhauser）、OpenClaw（Peter Steinberger）、Revolut（Vlad Yatsenko）、Sentry（David Cramer）和 Slack（Cal Henderson）的創始人等支援。

與我們合作的這些人，是朋友與導師、同事與夥伴。他們都投入於深厚、長期的關係，其中許多人也為自己創辦的機構和公司傾注了多年時間。能與他們同行，我們感到自豪。

——Armin 與 Colin
