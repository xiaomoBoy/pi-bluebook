# 實作案例

這裡不重複講一遍概念。每個案例都歸屬於一個藍皮書模組，從一份明確材料開始，寫清任務、限制、預期結果和失敗後的恢復方式，讓讀者可以在自己的環境裡完整復現。

## 案例結構

每個正式案例都應包含：

1. 可以下載或自行準備的練習材料；
2. 一段可以直接交給 Pi 的任務說明；
3. 執行過程中應該看到的關鍵現象；
4. 不依賴 Agent 自述的驗收方法；
5. 出錯後保留現場和恢復的方法。

## 案例路線圖

七個案例把後半本課程中的方法落到固定材料、可複製任務、關鍵現象、獨立驗收和失敗恢復。教學程式碼只用於最小、非破壞性練習；涉及真實桌面通知、遠端伺服器或陌生外掛程式的進階效果，仍以實際環境驗收為準。

| 順序 | 模組 | 案例 | 核心證據 |
| --- | --- | --- | --- |
| 01 | 模組二 | [會議記錄行動清單](/zh-TW/cases/meeting-notes) | 輸入指紋不變，三項欄位逐項對應 |
| 02 | 模組三 | [壓縮前後對照](/zh-TW/cases/compaction-before-after) | 同一 工作階段（Session）、記憶回答與磁碟恢復分開檢查 |
| 03 | 模組四 | [把方法整理成 技能（Skill）](/zh-TW/cases/first-skill) | 顯式載入、生成新檔案、退出後停用 |
| 04 | 模組四 | [載入最小 擴充功能（Extension）](/zh-TW/cases/first-extension) | 命令出現、執行、重啟後消失 |
| 05 | 模組四 | [兩路獨立審閱](/zh-TW/cases/independent-review) | 兩份隔離證據由主工作階段統一合併 |
| 06 | 模組五 | [從檢查點恢復](/zh-TW/cases/checkpoint-recovery) | 三篇材料不重不漏，進度與產物一致 |
| 07 | 模組五 | [任務前安全審閱](/zh-TW/cases/safe-review) | 未知保留為未知，危險動作沒有執行 |

模組一暫不另設 CASE：安裝、Windows 路徑、登入和練習目錄本身已經是逐步實作。模組三隻新增一個對照實驗，不增加新課。
