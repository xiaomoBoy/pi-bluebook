# 安裝 Pi，並第一次開啟它

上一課準備好了終端機、空白練習目錄、Node.js 和 npm。現在只做一件事，讓 `pi` 命令能在這臺電腦上正常開啟和退出。

::: info Windows 使用者
本頁的快捷鍵和目錄按 macOS 編寫。Windows 使用者請改走 [Windows 中文安裝路徑](/zh-TW/guide/windows-setup)，不要在命令提示符或 PowerShell 中直接照抄本頁；獨立路徑完成安裝和第一次啟動後，會接回第 3 課。
:::

先開啟終端機。如果你不確定自己現在在哪，先輸入 `pwd` 看一眼。下面第一條安裝命令安裝的是電腦可呼叫的 Pi 命令；後面“啟動 Pi”時所在的目錄，才決定 Pi 會看到哪些檔案。

## 1. 執行官方安裝命令

用滑鼠選中下面**整行**，按 `Command + C`；點回終端機的閃爍游標，按 `Command + V`，確認沒有多出其他文字後按回車。

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

`-g` 表示把 Pi 安裝成這臺電腦可以直接呼叫的命令。`--ignore-scripts` 會禁止依賴包在安裝時執行生命週期指令碼；Pi 的正常 npm 安裝不需要這些指令碼。

按回車後，終端機會陸續顯示下載和安裝資訊。這是正常的等待過程，不需要繼續輸入。只有同時滿足下面三點，安裝才算透過：

1. 終端機重新出現可以輸入的游標；
2. 最後沒有出現以 `npm ERR!` 開頭的錯誤。
3. 緊接著執行 `pi --version` 能返回版本號。

如果安裝超過一會兒仍在滾動文字，繼續等待；如果文字停止但游標沒有回來，也先不要輸入下一條命令。網路慢時下載會比普通命令花更久。

安裝過程結束後，檢查它是否真的可用。

```bash
pi --version
```

這裡輸入的是 `pi --version`，隨後出現的一串版本號才是輸出。看到版本號、並且游標重新出現，而不是 `command not found`，就算透過。本書不把某個具體 Pi 版本當成永久要求，安裝命令核驗於 2026-09-09，後續以 [Pi 官方 Quickstart](https://pi.dev/docs/latest/quickstart) 為準。

![在真實終端機中檢查 Node.js、npm 與 Pi 版本](/images/01-Pi-版本检查-实操图.png)

這張圖記錄的是 2026-09-09 的本機教學環境。你的版本號可以更新，判斷方法保持不變：三條檢查都有輸出，命令執行結束後終端機游標重新出現。它只能證明當前環境已經裝好，不能當成首次安裝過程的截圖。

### 小檢查

- [ ] 安裝命令已結束，終端機沒有顯示 `npm ERR!`。
- [ ] `pi --version` 顯示了版本號。
- [ ] 我沒有為安裝輸入 `sudo`，也沒有輸入電腦賬戶密碼來繞過報錯。

## 2. 第一次啟動

先確認仍然在練習目錄，再啟動 Pi。

```bash
cd ~/Downloads/pi-practice
pwd
pi
```

這三行依次執行。`pwd` 的輸出必須以 `/Downloads/pi-practice` 結尾；如果你在上一課用了 `pi-practice-2`，這裡也要把命令中的目錄名換成自己的名字。確認路徑後，才輸入最後一行 `pi`。

第一次開啟時，Pi 可能要載入一會兒。完成後，你會看到可以輸入訊息的編輯區，下方狀態列會顯示當前目錄和模型。這時你已從普通終端機進入 Pi 互動介面；不要把 Pi 介面中的狀態列文字當作終端機命令輸入。

如果它提示登入，這不代表安裝失敗。認證放在下一課處理。

如果底部顯示的目錄不是剛才 `pwd` 看到的練習目錄，不要傳送任何任務：在 Pi 中輸入 `/quit`，回到終端機後重新執行本節的三行命令。

### 小檢查

- [ ] 啟動前的 `pwd` 顯示練習目錄。
- [ ] Pi 介面已經出現輸入區和底部狀態列。
- [ ] 我尚未在 Pi 中要求它讀取、建立、修改檔案或執行命令。

## 3. 學會回到終端機

現在注意：下面的 `/quit` 是**Pi 介面裡**的命令，不是在普通終端機裡輸入。先點選 Pi 的輸入區，輸入它並按回車。

```text
/quit
```

Pi 關閉後會回到原來的終端機提示符。此時再輸入一次 `pi` 並按回車；能再次看到 Pi 介面，說明你已經分清了“終端機命令”和“Pi 內命令”兩個狀態。第二次開啟後可再次輸入 `/quit`，為下一課做準備。

::: warning 遇到常見失敗時
- 安裝過程出現 `npm ERR!` 或 `EACCES`，不要直接加 `sudo`。先等命令結束；然後拖選“安裝命令”到最後一行報錯，按 `Command + C` 儲存完整文字，再確認 Node.js 來自官方 LTS 安裝。
- 安裝成功後仍提示 `pi: command not found`，完全退出終端機並重新開啟，再執行 `pi --version`。不要自行修改 PATH。
- 網路下載失敗，確認網路後用同一條官方命令重試一次，先別混用多個安裝器。
- 安裝過程中突然出現要求輸入密碼的提示，不要為了繼續而輸入密碼。先按 `Control + C` 停止，保留螢幕上的文字，再檢查自己是否誤加了其他命令。
:::

## 本課驗收

- `pi --version` 能返回版本號。
- 我能從自己新建的練習目錄啟動 Pi。
- 我能用 `/quit` 退出，再重新啟動。
- 我知道：終端機游標回來才表示命令已結束；不明白的報錯先完整保留，不靠 `sudo` 或隨機命令處理。
