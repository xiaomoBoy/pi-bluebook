# 從 98 條推文留下的十條判斷

98 條推文記錄的是一個持續學習的過程。裡面既有後來保留的判斷，也有被後續實踐修正的猜測、當時有效的價格與短期產品狀態。

本頁不重寫推文，也不把個人體驗直接包裝成官方結論。它只收錄在多次實踐中反覆出現、與本書當前課程一致、截至本版核驗時仍可作為學習原則的十條判斷。想看形成過程，可以回到[推文學習目錄](/zh-TW/tweets/)閱讀原文。

## 1. 新手最大的障礙往往是使用成本，不是概念

理解 Agent、工作階段（Session） 或 上下文（Context） 需要時間，但真正阻止許多人繼續練習的，常常是沒有可用的模型存取方式，或無法判斷一次任務會消耗多少額度。開始前先弄清訂閱登入、API Key、餘額和限額，比先比較模型排行榜更實際。

**落到課程裡：** [第 3 課](/zh-TW/guide/connect-model)先完成一種可用認證和一次無檔案呼叫；正式任務從小材料開始。

## 2. Pi 的價值不是功能最多，而是底座足夠小

Pi 把模型、工具、工作階段 和上下文連接起來，核心保持克制，更多能力按需擴充。這不是“尚未做完”，而是一種把工作流決定權交還給使用者的設計。

**落到課程裡：** 先學預設能力，再[區分 技能（Skill）、擴充功能（Extension） 與 套件（Package）](/zh-TW/guide/skills-extensions-packages)，不用功能數量評價 代理框架（Agent Harness）。

## 3. 先裝全家桶，會失去對因果的判斷

同時加入多個外掛程式後，一項能力究竟來自核心、模型還是某個擴充，常常說不清；出錯時也難以定位衝突。新手更需要一個可解釋的環境，而不是一個看起來無所不能的環境。

**落到課程裡：** 保持最小配置，出現真實需求後一次只試一個外掛程式；啟用前後都留下可觀察結果。

## 4. 技能 應從重複工作里長出來

收藏別人的 技能 不等於建立自己的工作流。更可靠的做法，是先完成幾次真實任務，找出反覆出現的審閱、整理或釋出步驟，再把已經穩定的方法寫成 技能。

**落到課程裡：** 第一個 技能 從已有行動清單中提煉規則，而不是先瀏覽市場湊數量。

## 5. 一件事使用一條 工作階段

登入、寫文章、改程式碼和隨手問答都擠在同一條 工作階段，模型會面對互不相關的歷史。方向已經混亂時，繼續解釋或等待壓縮，往往只會把混亂保留下來。

**落到課程裡：** [為任務建立可搜尋的獨立 工作階段](/zh-TW/guide/sessions)；走偏時回到分叉點，或及時開啟新工作階段。

## 6. 工作階段 可儲存，不等於模型始終記得全部內容

工作階段 儲存的是可繼續處理的歷史結構；模型每一輪看到的 上下文 只是從中構造出來的一部分。完整歷史仍在檔案裡，並不保證每個舊細節一直位於當前上下文視窗。

**落到課程裡：** 把真正不能丟的目標、約束、決定和下一步寫進檢查點檔案，不把長期任務只寄託在聊天記憶上。

## 7. 壓縮與提示快取必須分開理解

壓縮是為了在上下文接近上限時用摘要替代部分舊歷史；提示快取是服務商對穩定字首的複用與計費機制。一次壓縮可能改變字首並降低當時的快取命中，但兩者不是同一個功能，也不能用快取數字判斷任務質量。

**落到課程裡：** 模組三分別學習[壓縮](/zh-TW/guide/context-and-compaction)和[提示快取](/zh-TW/guide/prompt-caching)，驗收仍回到檔案、約束與最終產物。

## 8. 子代理（Subagent） 首先是分工方法，不是一個內建按鈕

Pi 預設不把子代理 固化進核心。真正重要的是能否把搜尋、整理、執行和複核拆成邊界清晰的任務，並說明每一份結果怎樣交回。沒有這種能力，增加 Agent 數量只會放大成本和溝通損耗。

**落到課程裡：** [先用兩個獨立工作階段練習分工和交接](/zh-TW/guide/subagents)，再決定是否安裝多代理 擴充。

## 9. 提示詞規定範圍，作業系統決定權限

“只改這個目錄”能夠幫助模型理解任務邊界，卻不是技術隔離。Pi 的工具和 擴充功能 以當前程序擁有的權限執行；面對不可信程式碼和材料時，需要容器、虛擬機器或專用賬戶等真正的隔離措施。

**落到課程裡：** [專案信任（Project Trust） 不當作沙箱](/zh-TW/guide/safety)，敏感憑據不進入提示、截圖或倉庫，危險操作由外部環境限制。

## 10. 完成宣告不能替代獨立驗收

Agent 說“已經完成”，只代表它做出了判斷。檔案是否存在、內容是否完整、命令是否成功、線上版本是否更新，必須使用不依賴該宣告的證據檢查。

**落到課程裡：** 每一課都設定可見的完成標誌；重要修改要讀取產物、執行檢查並核對最終狀態。

## 檔案和藍皮書的分界

推文繼續保留髮布日期、原始表達和認識變化，不因為本頁出現而回寫。涉及具體模型、價格、免費期、外掛程式狀態和短期推薦的內容，也不會提升為長期結論。

本頁的十條判斷會隨著正式版次審閱；網站可以補充證據或糾正表述，但不會追著每一次生態變化擴張成排行榜。
