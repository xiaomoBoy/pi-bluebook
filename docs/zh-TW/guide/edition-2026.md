# 凡例與 2026 開放學習版說明

這是一份面向中文初學者的 Pi 學習藍皮書。網站會持續維護，**2026 開放學習版**則是一套範圍明確、可以被引用和複核的內容編排。

| 專案 | 說明 |

“開放學習版”不是“所有頁面永遠不再變化”。它表示本版的讀者物件、學習順序、基本主張和內容邊界已經確定；釋出後的改動需要遵守下面的維護規則。

## 閱讀凡例

### 1. 主線以 macOS 為準，Windows 走獨立入口

主線截圖、快捷鍵和常用目錄以 macOS 為基準。Windows 使用者先閱讀[Windows 中文路徑](/zh-TW/guide/windows-setup)，在 Git Bash 中完成安裝與首次啟動，再接回第 3 課。Linux 讀者可使用 macOS/Linux 通用命令，並自行替換主目錄路徑。

### 2. 動態事實看頁內日期

模型名稱、模型服務商（Provider）、登入方式、命令引數、價格、額度和第三方專案狀態都會變化。涉及這些內容時，應同時檢視頁面的最後更新日期，並以 [Pi 官方文件](https://pi.dev/docs/latest)及對應服務商的當前說明為準。

本書不維護模型價格表或外掛程式排行榜。過期的具體數字會校訂或標註日期，但不會把短期促銷提升為長期建議。

### 3. 截圖幫助定位，不替代操作步驟

截圖用於確認介面區域、狀態和成功訊號。介面更新後，按鈕位置和文字可能變化；讀者應按正文中的目標、步驟與驗收繼續判斷，而不是隻尋找一張完全相同的畫面。

涉及系統級結果時必須使用對應證據。例如，終端機裡列印通知文字，不等於桌面通知已經出現；沒有真實系統截圖和復現場景的功能，會明確標為未驗收或進階內容。

### 4. 命令塊預設需要逐行理解

命令中的目錄名、檔名和示例值只適用於相應練習。貼上前先確認當前目錄，不把真實 API Key、主密碼、私人路徑或生產憑據寫進提示、截圖和倉庫。

破壞性操作不會因為出現在教學裡就自動安全。遇到與自己環境不一致的路徑，先停止並核對目標。

### 5. “完成”必須有外部證據

每一課給出完成標誌或驗收步驟。Agent 的自我總結、瀏覽器裡的成功提示、終端機的一行輸出，都只代表部分訊號；最終應檢查檔案、內容、測試、遠端狀態或真實介面。

## 網站與固定版怎樣維護

- **網站可以持續校訂：** 修正錯字、失效連結、已變化的命令和核驗日期；補充不會改變學習結構的說明。
- **本版結構保持穩定：** 導論、序章、五個模組、案例、外掛程式推薦、授權譯文和附錄構成 2026 開放學習版的基本目錄。
- **重大變化另起版次：** 如果 Pi 的安裝、核心概念或學習路徑發生結構性變化，應更新版次說明，而不是悄悄改寫舊版主張。
- **PDF 使用明確快照：** 後續釋出的 PDF 將標出生成日期、內容核驗截止和對應提交，方便下載、列印和引用。
