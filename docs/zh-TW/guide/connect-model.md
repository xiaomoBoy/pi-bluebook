# 登入使用者帳戶，讓 Pi 能回答你

Pi 提供互動介面和檔案工具，真正生成回覆的是你選擇的模型服務。所以安裝完 Pi 後，還需要連接一個你已經可以使用的服務。

開始前，你需要已經擁有一種可用憑據：官方當前支援的訂閱登入，或對應模型服務已啟用的 API Key。只有聊天產品使用者帳戶、不含 API 使用額度的使用者帳戶，未必能在 Pi 中呼叫模型。訂閱登入可能開啟瀏覽器；API Key 路線通常由模型服務商按使用量計費。

::: warning 先確認費用，再登入
**訂閱不等於 API，能登入也不等於呼叫免費。** 不同模型服務商（Provider）的訂閱認證、方案額度、額外用量和 API 餘額規則不同；有些路線即使使用訂閱使用者帳戶授權，第三方代理框架（Agent Harness）中的呼叫仍可能進入單獨計費。不要根據聊天產品頁面上的“已訂閱”推斷 Pi 中的費用。
:::

::: info Windows 使用者
如果你剛完成 [Windows 中文安裝路徑](/zh-TW/guide/windows-setup)，本課和後續課程中的“普通終端機”都指 Git Bash。下面的 `~/Downloads/pi-practice` 請換成你已建立的 `~/pi-practice`；Pi 編輯區裡的 `/login`、`/model` 等命令不變。
:::

## 先選模型存取方式：官方 API 與訂閱

以下價格和接入方式核驗於 **2026 年 9 月 14 日**。四種選擇適合不同需求，選一種能跑通練習的即可；模型名單、價格、額度和活動可能變化，付款前再開啟對應官方頁面核對。

**推薦說明：** 這些是我根據入門成本和 Pi 接入方式整理的個人選擇，與下列服務商沒有贊助、返傭或其他利益關係；文中的連結均指向官方頁面，不含我的邀請連結。

### DeepSeek 官方 API · 按量計費

適合想先用一個國內模型、按實際用量付費的讀者。到 [DeepSeek 官方平台](https://platform.deepseek.com/)開通 API、建立 Key 並確認餘額；Pi 內建 `deepseek` 模型服務商，可在 `/login` 中選擇 DeepSeek 輸入官方 Key，再用 `/model` 檢視當前可選模型。[Pi 官方接入說明](https://pi.dev/docs/latest/providers)列出 `DEEPSEEK_API_KEY`。這**不是包月訂閱**：呼叫按輸入、輸出 Token 扣費，快取是否命中、模型以及高峰/低峰時段都會影響價格。[DeepSeek 官方價格表](https://api-docs.deepseek.com/quick_start/pricing)會更新，首次測試前先看當前餘額和計費規則。

### ChatGPT Plus · $20/月

適合主要想用 OpenAI 的 Codex 模型，同時也使用 ChatGPT 的讀者。[OpenAI 官方價格](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)為 $20/月。Pi 支援在 `/login` 中選擇 **ChatGPT Plus/Pro (Codex)**，但可選模型以當前使用者帳戶和 Pi 的模型清單為準；不能寫成“GPT 全系列都能在 Pi 中使用”。Plus 也不包含單獨計費的 OpenAI API 用量。[檢視 Pi 接入說明](https://pi.dev/docs/latest/providers)

### OpenCode Go · $10/月

適合想以較低月費使用多種編碼模型的讀者。[Go 官方說明](https://opencode.ai/docs/go/)列出 $10/月；Pi 內建 `opencode-go` 模型服務商，用 Go 的 API Key 登入。當前名單有 GLM、Kimi、Qwen、DeepSeek、MiniMax、MiMo，也有 GPT、Grok 等，不能概括為“全是國內模型”。不同模型的月度用量上限不同；5 小時和每週視窗分別最多使用該模型月限額的 20% 和 50%。[檢視 Pi 接入說明](https://pi.dev/docs/latest/providers)

### Command Code GOAT · $10/月

適合願意設定自定義模型服務商、想在多種模型間切換的讀者。[GOAT 官方說明](https://commandcode.ai/docs/plans/goat)列出 $10/月；其 [模型服務商 API](https://commandcode.ai/docs/provider) 可使用方案內模型和額度。Pi 沒有預設的 GOAT 登入項，需要按 [Pi 自定義模型說明](https://pi.dev/docs/latest/models)接入相容 API。名單同時包括國內開放模型與部分 GPT、Gemini、Grok 等模型。官方列出 5 小時 $14、每週 $35 的用量視窗；每月具體可用量還要看所選模型。

**怎麼選：** 想用國內模型且只按實際用量付費，先看 DeepSeek 官方 API；想使用 OpenAI 的 Codex 模型並同時使用 ChatGPT，先看 ChatGPT Plus；想以較低月費試用多種編碼模型，再看 OpenCode Go；願意自己設定介面、也需要 GOAT 模型名單時，最後考慮 Command Code GOAT。“可以高強度使用”只表示部分方案有一定用量空間，**不表示無限呼叫**；按量付費的 API 則應自行留意餘額與消費。第一次試用仍要檢視帳戶裡的額度和是否開啟額外付費。

OpenCode Go 的“邀請他人可得 $5”目前沒有在其公開的 [Go 官方說明](https://opencode.ai/docs/go/)中找到固定活動條款，因此不計入上述價格或額度。若你的帳戶顯示邀請活動，請以當時後台列出的獎勵型別、領取條件和有效期為準；使用額度獎勵不等於月費減免。

## 1. 選擇一種登入方式

先用下面這張表決定自己走哪條路。不要因為清單中某個模型看起來更強，就臨時開通一項還沒理解的付費服務。

| 你已經擁有的存取方式 | 在 Pi 中的入口 | 開始前必須確認 |
| --- | --- | --- |
| Pi 官方當前列出的受支援訂閱 | 對應模型服務商的訂閱/OAuth 登入 | 訂閱等級是否符合要求；Pi 中的呼叫使用方案額度、額外用量還是其他餘額 |
| 已訂閱並取得 API Key，或已有 API 餘額；Pi 內建該模型服務商 | 在 `/login` 中選擇對應模型服務商的 API Key | Key 屬於哪個帳戶；計費方式、餘額或限額；怎樣撤銷 Key |
| 方案提供相容 API，但 Pi 未內建該模型服務商（如 GOAT） | 先看 [Pi 自定義模型說明](https://pi.dev/docs/latest/models)；本課的登入選單沒有現成入口 | 方案是否開放 API、怎樣設定 Key、模型是否在方案內以及用量限制 |
| 只有普通聊天產品使用者帳戶 | 先不要繼續 | 該使用者帳戶是否真的包含 Pi 支援的模型存取方式 |
| 兩者都沒有或無法確認 | 先不要繼續 | 先閱讀模型服務商當前說明，不為完成教學盲目充值 |

在接入前，先完成三個檢查：

1. 說清自己使用的是“訂閱認證”還是“API Key”，不能只說“我有使用者帳戶”。
2. 在對應服務商帳戶中確認計費或額度狀態；上面的價格只是註明核驗日期的選擇參考，不代替付款頁和帳戶餘額。
3. 把本課停止條件設為一次無檔案連通測試。沒有確認費用前，不開始長任務，也不連續切換多個模型試跑。

如果你上一課後已經退出 Pi，先在終端機重新進入練習目錄。

```bash
cd ~/Downloads/pi-practice
pwd
pi
```

如果你在第 1 課使用了其他練習目錄名，先把命令中的 `pi-practice` 替換掉。確認 `pwd` 以你實際的練習目錄名結尾。使用 Pi 內建模型服務商的讀者，進入 Pi 後輸入：

```text
/login
```

這條 `/login` 要輸入在 **Pi 底部的編輯區**，不是退回普通終端機後輸入。輸入完按 `Return`。選單出現後，用上下方向鍵移動選中項，按 `Return` 確認，按 `Esc` 返回上一層或取消。

![Pi 中開啟的真實登入方式選擇選單](/images/02-Pi-登录方式-实操图.png)

截圖停在選擇入口，沒有繼續提交使用者帳戶或憑據。藍色箭頭表示當前選中項；你可以在使用者帳戶登入與 API Key 兩條路線之間移動。任何真實 Key、驗證碼和使用者帳戶資訊都不應進入教學截圖。

按介面提示選擇一條路線，並只完成剛才確認過的那一種。

- 已有受支援的訂閱，選擇對應服務，按瀏覽器授權流程完成登入。瀏覽器授權成功只能證明憑據已返回，不能證明後續呼叫不產生費用。
- 已有 API Key，選擇對應服務，只在 Pi 本機登入介面中輸入。API Key 是呼叫憑據，不是免費額度；實際費用和限制由該 Key 所屬帳戶決定。

如果任何步驟要求把 Key 寫進專案檔案、聊天輸入區、截圖或普通終端機命令歷史，按 `Esc` 取消，不繼續貼上。本課只接受 Pi 的本機認證入口或官方明確說明的環境設定方式。

某些登入方式會自動開啟瀏覽器。在瀏覽器中確認完成後，回到原來的終端機視窗。終端機中重新出現 Pi 的輸入區，才表示登入流程已經返回。不要因為瀏覽器顯示“成功”就關閉整個終端機。

官方當前支援的訂閱、API Key 和提供商規則會變化，請以 [Pi 模型服務商](https://pi.dev/docs/latest/providers) 為準，並繼續檢視所選服務商的計費說明。某個聊天產品使用者帳戶存在，不代表它一定包含 Pi 所需的模型存取權限。

::: danger 不要公開憑據
不要把真實 API Key 貼進聊天、教學、截圖或 GitHub 倉庫。如果懷疑金鑰已洩露，立即到服務商後台撤銷舊金鑰並建立新金鑰。
:::

## 2. 選擇當前使用者帳戶可用的模型

接入完成後，輸入：

```text
/model
```

用上下方向鍵移動，按 `Return` 選中模型。清單關閉並回到編輯區後，檢視底部狀態列，確認當前模型名已經顯示。

![Pi 中開啟的真實模型選擇器](/images/03-Pi-模型选择-实操图.png)

選擇器只顯示當前已設定模型服務商可用的模型。截圖中的清單會隨使用者帳戶和時間變化；綠色勾與藍色箭頭幫助確認當前項，選中後仍要回到底部狀態列複核模型名。

如果希望下次啟動繼續使用它，在模型選擇器中按 `Ctrl+S` 儲存為啟動預設值。不要把教學中的某個模型名稱當成唯一正確答案，模型的名稱、可用性和計費都會變化。

## 3. 做一次無檔案操作的連通測試

回到編輯區，提交這句話：

```text
只回復“Pi 已連接”。不要讀取、建立、修改檔案，也不要執行命令。
```

貼上到 Pi 底部編輯區後按 `Return`。介面可能會先顯示正在思考或等待網路，這時不要重複提交。等到模型真正返回文字，並且底部編輯區再次可輸入，才是這輪結束。

看到完整的“Pi 已連接”回覆才算透過。泛泛的歡迎語、只看到“登入成功”提示，都不能證明當前模型完成了這次真實呼叫。

如果 Pi 準備讀寫檔案或執行命令，按 `Esc` 中止。這次測試不需要任何工具。

::: warning 沒有收到回覆
- 看不到可用模型，內建模型服務商先回到 `/login` 檢查認證；自定義模型服務商先檢查模型設定。
- 選完模型但狀態列沒有變化，先取消當前操作，重新開啟 `/model` 核對；不要連續切換多個提供商。
- 測試請求長時間不返回，先按 `Esc` 停止這一輪，保留狀態列模型名和錯誤文字，再檢查網路與該服務狀態。
- 出現 `unauthorized`、餘額或額度錯誤，保留原始文字，檢查當前使用者帳戶權限。
- 瀏覽器授權後沒有回到 Pi，取消本次登入，確認瀏覽器中的使用者帳戶後再重試。
- 不知道錯誤在哪裡，從第一行錯誤到底部輸入區整段複製，但要先遮住 API Key、郵箱和私人路徑。
:::

## 本課驗收

- 能明確說出本次使用的是訂閱認證還是 API Key，並已檢視對應帳戶的額度或計費狀態。
- 已透過 `/login` 完成認證，或已設定一種可用的自定義模型服務商。
- 底部狀態列顯示當前模型。
- 測試準確回覆“Pi 已連接”，且沒有工具呼叫。
