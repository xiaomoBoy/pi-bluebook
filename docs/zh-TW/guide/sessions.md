# 工作階段的儲存與續寫

做完第一個任務後，很多人會問：關閉終端機以後，剛才的對話是不是沒有了？

Pi 預設會自動儲存工作階段，並按工作目錄組織。你無需每說一句就手動儲存，但需要學會給工作階段起名字，否則日後會很難找回來。

工作階段預設儲存在 `~/.pi/agent/sessions/` 下，並按工作目錄組織成 JSONL 檔案。在 Pi 中輸入 `/session` 可以看到當前工作階段檔案、ID、訊息數、token 與成本；這裡可能包含私人提示、路徑和工具結果，不要直接上傳或公開。

## 一件事對應一個工作階段

一個實用的起點規則是：一個明確目標，使用一個工作階段。整理會議記錄、修復網站導航和翻譯一篇文章，最好不要全部塞進同一條對話。

任務開始後，在 Pi 輸入區輸入：

```text
/name 會議記錄整理練習
```

名字應該描述任務，而不是寫“測試 1”或“今天的對話”。一週後回來，你仍然能從名字判斷內容。

輸入完按 `Return`。`/session` 可以檢視當前工作階段檔案、ID、訊息數、token 與成本資訊；工作階段名最直接的複核入口是稍後的 `/resume` 選擇器。先繼續完成本節的退出與恢復練習。

## 關閉以後繼續做

如果你剛退出 Pi，而且要繼續當前目錄最近的工作階段，先在普通終端機回到練習目錄：

```bash
cd ~/Downloads/pi-practice
pwd
pi -c
```

`pwd` 必須顯示正確的練習目錄。`pi -c` 開啟後，先檢查歷史訊息確實屬於剛才的會議記錄任務；需要核對名稱時開啟 `/resume`，列表中應能找到“會議記錄整理練習”，按 `Esc` 取消選擇並回到當前工作階段。

如果這個專案有多個工作階段，使用：

```bash
cd ~/Downloads/pi-practice
pwd
pi -r
```

這會開啟歷史工作階段選擇器。用上下方向鍵找到對應名稱，按 `Return` 開啟，按 `Esc` 取消。也可以在已開啟的 Pi 中輸入 `/resume`。選擇前先看工作階段名和工作目錄，別把相似專案接錯。

如果你使用的練習目錄名不是 `pi-practice`，把兩處 `cd` 命令裡的目錄名一起替換掉。

### 沒有回到預期工作階段時

- `pi -c` 開啟的歷史不對：不要在這個工作階段繼續寫檔案，輸入 `/quit`，確認 `pwd` 後改用 `pi -r`。
- `pi -r` 列表為空：先確認當前工作目錄是否與建立工作階段時相同。Pi 的工作階段按工作目錄組織，目錄不一致時看不到同一組工作階段。
- 誤選了相似名稱：用 `/session` 核對後立即退出，再重新選擇。
- 工作階段確實找不到：不要宣稱對話已經恢復。新建工作階段，讓 Pi 重新讀取專案中的輸入、輸出和交接檔案，從磁碟產物繼續。

::: tip 你現在只要記住兩個入口
`pi -c` 續寫最近工作階段，`pi -r` 從列表中選擇。其他選項可以等真正遇到需求再學。
:::

## 走錯方向時認識 `/tree`

對話不是只能一路向下。Pi 的工作階段以樹狀結構儲存。在互動介面輸入 `/tree`，可以回到之前的某個節點，然後從那裡繼續。本課先把它作為進階入口，不要在重要工作階段中隨意跳轉。

適合使用的場景包括：

- 你發現三輪之前就理解錯了任務。
- 想保留當前方案，同時嘗試另一條路。
- 對話已經被臨時除錯資訊佔滿，想從比較乾淨的節點重新開始。

跳轉不會把已經寫入磁碟的檔案恢復到早期狀態。工作階段樹管理對話歷史，Git 或備份才管理檔案版本。

`/tree` 只在同一個 JSONL 工作階段檔案裡移動當前節點；`/fork` 會從先前的使用者訊息建立新工作階段，`/clone` 會把當前活動分支複製成新工作階段。離開當前分支時，Pi 還可能詢問是否為離開的路線生成 Branch Summary。摘要用於把有用資訊帶到新路線，不會回滾磁碟檔案。

如果你有一份來自其他位置的工作階段檔案，可以用 `pi --session <路徑或ID>` 開啟，或在互動介面使用 `/import <檔案>` 匯入。先確認檔案來源，因為其中可能包含私人內容、專案路徑和工具記錄。

初學時不必在重要工作階段中強行練習分支。等你有一個可以丟棄的測試工作階段，再輸入兩條不同方案，用 `/tree` 回到分叉前的使用者訊息繼續另一條路線。驗收重點不是介面有樹，而是你能明確說出：切換對話節點以後，剛才已經寫入的磁碟檔案仍然需要單獨核對或恢復。

## 新任務就新建工作階段

當目標已經變了，在 Pi 中輸入 `/new`。之前的工作階段仍然保留，新任務會獲得一個乾淨起點。

## 本課驗收

離開本章前，完成一次固定練習：

1. 給當前工作階段命名，開啟 `/resume` 並在列表中看到名字，然後按 `Esc` 返回。
2. 用 `/quit` 退出，確認回到普通終端機。
3. 在正確目錄執行 `pi -c`，核對歷史訊息，並在 `/resume` 列表中再次找到名稱。
4. 確認先前訊息仍在，再開啟上一課的輸出檔案，確認磁碟產物也在。

名稱、歷史訊息和工作目錄都一致，說明恢復了正確工作階段；輸出檔案仍在只能證明磁碟內容存在，兩類證據不要混為一談。
