# 關於作者

我是小墨，一名獨立開發者，也是 [Pi 學習藍皮書](/zh-TW/) 的整理者。我平時做 Agent 相關的實踐、寫作與開源工具，也參與 [AI Spark](https://aisparkedu.com/) 的工作。

## 為什麼寫這本書

最初只是好奇：一個看起來很簡潔的 Pi，為什麼能成為許多工作流的起點？我從自己動手做第一個任務開始，留下學習記錄，後來讀原始碼、試著寫擴充功能（Extension），也不斷修正早先的判斷。

記錄越多，越覺得新手需要的不只是一份功能清單，而是一條能從第一次任務走到自己搭建工作流、每一步都知道怎樣檢查結果的路線。這就是藍皮書的來由。仍在變化的個人想法和試錯，留在[小墨札記](/zh-TW/journey/)；經過重新核驗、適合照著操作的內容，才放進主線。

## 我怎樣判斷一件事做成了

比起 Agent 說自己做完了，我更關心結果能不能跑通、復現，並由自己驗收。所以這裡儘量按“場景 → 概念 → 實作 → 驗收”來寫；發現舊判斷不準確，也會回頭改。
