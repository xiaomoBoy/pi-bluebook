# 邀请你开启一场通信

> - **原文标题**　*An Invitation to Begin a Correspondence*
> - **作者**　Armin Ronacher 与 Colin Daymond Hanna，Earendil `<rfc@earendil.com>`
> - **发布日期**　2026-01-18
> - **原文地址**　[earendil.com/posts/invitation](https://earendil.com/posts/invitation/)

> - **译文许可**　[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.zh-hans)

你好：

我们相信，应当以开放的方式建设，分享我们学到的东西、亲手打造的东西，以及未来要去的方向。

如果你也对能够增强人类自主权、弥合理解的软件感到好奇，我们很希望你加入这段旅程。[留下你的电子邮箱](https://earendil.com/posts/subscribe/)，就可以收到我们的文章：关于我们正在建造什么、它为什么重要，以及我们正在共同塑造什么的坦诚思考。

这些文字由人类书写，而不是机器。

我们欢迎你的评论。我们在奥地利维也纳工作——一座拥有咖啡、文化和愉快交谈的城市。如果你恰好经过这里并想来打声招呼，请写信到 `rfc@earendil.com`。

大门敞开着。

谨致问候，

Armin 与 Colin
