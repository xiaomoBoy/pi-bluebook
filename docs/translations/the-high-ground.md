# 制高点

> - **原文标题**　*The High Ground*
> - **作者**　Colin Daymond Hanna，Earendil `<rfc@earendil.com>`

## 引言

这份备忘录试图回答一个问题：在 2026 至 2031 年间，基础模型提供商之外的软件和计算领域，“制高点”会出现在哪里？

背景是 AI 的迅速普及：它一方面不断进入更广泛的消费者和企业软件场景，另一方面也越来越多地被用于编写软件。

## 消费者与企业软件中的 AI

预测 AI 会继续渗透软件，并不需要承担多大风险。与现状相比，这会催生四项主要变化：

1. **通用系统会以高度专业化系统的萎缩为代价不断增长。** 这源自所有主要 LLM 都具备的通用理解能力。
2. **软件系统可以通过自然语言控制和定制。**
3. **软件能够获得自我感知能力。** 把代码和用户行为输入 LLM，会产生一种近乎涌现的能力，形成能够感知自身的软件。
4. **上下文在高度通用的系统中占据首要地位。** 专业化不再源自软件预先确定的架构，而是来自运行或推理时，对最相关用户与业务上下文的广泛获取和审慎运用。

## 软件创造中的 AI

同样清楚的是，AI 正在显著改变软件的编写方式。我们也可以从四个维度描述这种变化：

1. **创造软件的成本会下降。** 世界上会出现更多软件。
2. **编写软件的人会改变。** 进入门槛正在降低。缺乏通用技术能力、却拥有专业知识和判断品位的人，也能驾驭具备通用能力的模型。
3. **由 LLM 编写的软件将成为中位数，也就是平庸的软件。** 真正能在细分领域胜出的优秀公司，要么由对高效、可扩展系统工程有独到见解的软件架构师引领，要么由兼具独特市场洞察与品位的工匠，驾驭 LLM 的通用能力来打造。
4. **AI 正在提高参与率。** 这既体现在谁能够编写软件，也体现在最终用户怎样按照自己的偏好改造软件。因此，最好的系统应当开放、可适应，允许更广泛的开发者社区参与贡献，同时也让最终用户拥有高度定制能力。

## 关于社交媒体的一点说明

即使机器还没有大规模进入社交媒体，人们对社交媒体的总体满意度也已经明显偏低。这些平台彼此割裂，所有权却越来越集中在少数人手中。算法把用户推向刺激与渴望不断循环的内容。

当你听餐厅和酒吧里的谈话时，毫不夸张地说，人们经常带着厌恶和自我责备谈论自己使用社交媒体的方式。我们不愿让孩子接触它，它也没有丰富我们的生活或人际关系。

当然，仍有少数社区从社交媒体中得到的好处多于伤害：那些因一门手艺、共同热情或兴趣而聚集起来的人。但这些真正有价值的角落，大多只是沙漠中的绿洲。

人类之间有意义的数字互动，主要仍存在于私密空间，例如即时通信、聊天、小部分论坛和电子邮件通信。

## 制高点

制高点将出现在这样一个交汇处：人与人彼此互动，同时也与能力卓越、可定制、个性化、令人愉悦、简单易用，并且能够保有用户信任的系统互动。下面逐项拆解这些特征。

### 互动

正如量子物理学家所知，宇宙更多地从事物之间怎样互动中涌现，而不是从事物本身是什么中涌现。当机器逐渐拥有理解人类自然语言的能力，我们会更希望让信息在互动中形成和流动，而不是建立并维护静态的信息结构。

### 能力

这意味着拥有最先进的 Agent 能力，同时保持精确，避免重大错误。

### 可定制

这意味着最终用户——无论个人、小企业还是公司——都能按照自身偏好，在最大程度上修改系统，并且可以轻松、直观地完成修改。

### 个性化

它超越可定制，尽管一部分个性化正是从定制中生长出来的。它意味着一个系统会逐步让最终用户感觉到：这个系统**属于自己**。它已经适应用户独特的生活背景和性格。

### 愉悦

系统本身会给最终用户带来惊喜和快乐。人与它互动时，能够感到一种惊奇与轻盈。

### 简单

开始使用软件以及继续与它互动，都不复杂。

### 赢得并保有信任

产品及其背后的公司应当以可信的方式呈现自己；透明地使用用户上下文；不滥用用户信任，也不让用户暴露在无法接受的安全风险中。

通过实现以上特征占据制高点，意味着能够解锁“使用”和“上下文”之间至关重要的正向循环：

> 使用越多，积累的上下文越深；上下文越深，系统行为越精确；系统表现得越精确——尤其是相对于同类或竞争者——用户就越愿意继续使用。

我们认为，只要系统能够保有上述品质，就应该尽可能归用户所有。

## 最后的思考

最后，让我们换一种方式理解这件事。

想象一座花园。让自己在脑海中置身其中。你选择种植什么，也悉心照料它。花园也许有篱笆，使它与别人的花园和空间有所区别。这里是一处安全空间，却没有与世界完全隔绝。天气、气候和外部世界仍会给你带来限制。

随着时间推移，花园会呈现出你怎样回应这些限制，也反映你多年来作出的决定。久而久之，花园会映照出你的样子。

你的花园里生活着一个实体。它扎根于花园，却又聪明、通晓世界、能力出众。它主要为了引导和帮助你而存在，也能与其他人互动。它深刻了解花园里的每一寸土地、每一朵初绽的花、每一枚果实，同时又能把花园里的一切与广阔的外部世界联系起来。

就像花园一样，这个实体也会逐渐映照出你。你可以把它派往花园之外；即使如此，它仍带着你在这片土壤中作出的选择所赋予的色彩，也始终扎根于此。

Earendil 正在建造这个实体，也在建造这座花园。我们的系统从两者之中涌现。

我们称它为 Lefos。
