# Pi 1.0

今天，我们自豪地发布 Pi 1.0：一个经过充分打磨、极简、可扩展，并且能由你自行塑造的 Agent Harness。每周，世界各地有数十万人使用 Pi。你们中的许多人提交了问题和 Pull Request。过去几个月，我们根据这些反馈不断改进、加固和演进 Pi，让它成为个人与企业都能依赖的稳定软件。

Pi 以极简著称，我们很在意守住这一点。Agent 工具每周都在变化，但许多变化并不会长久留下。Pi 的做法不同：我们会等一件事证明自身价值之后，再考虑是否采用，并权衡它实际提供的功能与必然增加的复杂度。本周早些时候，我们[在这篇文章里](/translations/you-said-no-mcp)进一步谈过这个过程，以及它与 Codemode、MCP 的关系。

今天发布的 Pi 1.0，就是这一过程的结果。Pi 已经可以运行各大提供商的最新模型，成为世界各地用户每天使用的编程助手，也为构建 Agent 应用提供了高度可塑的基础。随着 Pi 1.0 发布，我们为 Pi 带来了以下能力：

- Codemode：原生支持 MCP，也支持 Jev 和图像模型等非 LLM 模型。
- 扩展可以提供虚拟模型。
- 工具延迟加载。
- Anthropic 模型的缓存预热。
- 对话中途的系统消息：让提示和工具的变化能体现在转录记录中。
- 新的终端界面主题。
- 默认使用全屏模式。

其中许多功能，我们已经思考了数月。它们经过尝试，最终留了下来；没有留下的尝试要多得多。当我们使用加入这些新功能的 Pi 时，能感觉到它向前迈出了一大步，但它依然简单，依然是 Pi。

在持续打磨和演进 Pi 的同时，我们也逐渐发现，Pi 的某些形态并不适合许多人希望使用它的方式。在 Earendil，我们希望把 Pi 的极简理念，以及它让你驾驭 AI 的方式，带到编程助手和终端之外。它需要能从不同界面接入，支持更长时间运行的对话与任务。也就是说，Pi 需要变得更加持久可靠。为了不偏离极简的根基，也不把 Pi 硬改成另一种东西，我们把这些工作整合成一个新的实验性包，于今天一同发布：Pi Durable。

Pi Durable 是构建长期运行 Agent 应用的新基础，让这些应用的开发者和用户能够灵活地运用、引导背后的智能。它共享 Pi 的核心原则——极简与高度可塑性——同时把这些原则延伸到新的维度。Mario [在这里](/translations/pi-durable)详细介绍了我们如何打造 Pi Durable。

Earendil 成立的初衷，是打造增强人类自主能力的软件与开放协议。今天，我们把实现这一目标的工具交到大家手中。我们期待听到你们的反馈，也期待和大家一起，以开放的方式掌握未来。

Pi 1.0 今天就可以安装：

``` sh
curl -fsSL https://pi.dev/install.sh | sh
```

Windows 用户可以运行：

``` powershell
powershell -c "irm https://pi.dev/install.ps1 | iex"
```

Pi Durable 今天也已作为实验性包提供：

``` sh
npm install @earendil-works/pi-durable @earendil-works/pi-ai @earendil-works/chord
```

两者都采用 MIT 许可。文档位于 [pi.dev](https://pi.dev)，代码位于 [github.com/earendil-works/pi](https://github.com/earendil-works/pi)。

**原文录屏步骤（中文说明）**

1. Codemode：Pi 编写脚本，把一周的提交整理成简短摘要。

3. 重新加载，开启新会话，并选择新的 `router/auto` 模型。
4. 使用 Claude Opus 进行规划。
5. Jev 识别到工作进入实现阶段，交给 GPT 6 Luna。
6. 用 `!` 运行完成的脚本。
7. `/session` 按模型展示成本和缓存使用情况。
