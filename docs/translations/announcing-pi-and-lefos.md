# Pi 与 Lefos 正式发布

> - **原文标题**　*Announcing Pi & Lefos*
> - **作者**　Earendil `<rfc@earendil.com>`
> - **发布日期**　2026-04-08
> - **原文地址**　[earendil.com/posts/announcing-pi-and-lefos](https://earendil.com/posts/announcing-pi-and-lefos/)

[Earendil Inc.](https://www.earendil.com) 是一家由 Armin Ronacher 和 Colin Daymond Hanna 于 2025 年创立的公益公司。Earendil 的使命，是通过打造软件和开放协议，弥合分歧与无知，培养持久的喜悦与理解，从而增强人类的自主权。为了践行这些目标，Earendil 今天很自豪地宣布几项消息：

- Earendil 收购开源项目 [Pi](https://pi.dev)。Pi 由 Mario Zechner 创作，是当今软件工艺与品位的杰出范例。它既是 [OpenClaw 中的极简 Agent](https://lucumr.pocoo.org/2026/1/31/pi/)，也是已经得到广泛采用的开源编程 Agent 与 Harness。Mario 对开放和工艺的坚持，与 Earendil 的创立宗旨高度一致。在完成收购的同时，Mario Zechner 成为 Earendil 的重要股东和团队成员。
- [Lefos](https://lefos.com) 从今天起进入公开 Alpha 阶段。这是我们迈向一个长期目标的第一步：建立一种能够证明自己既拥有最大能力、又值得信赖的机器实体。Lefos 通过电子邮件与你和共同创作者沟通。这套技术栈由你控制，也允许你与其他人协作。Lefos 帮助你的收件箱成为深思熟虑的工作与沟通命令行。用户现在可以前往 [Lefos.com](https://lefos.com)加入候补名单。
- Earendil 很自豪地公布我们的早期支持者：Accel（Daniel Levine）、Balderton（Daniel Waterhouse），以及 n8n（Jan Oberhauser）、OpenClaw（Peter Steinberger）、Revolut（Vlad Yatsenko）、Sentry（David Cramer）和 Slack（Cal Henderson）的创始人等。感谢他们给予我们的信任与支持。
