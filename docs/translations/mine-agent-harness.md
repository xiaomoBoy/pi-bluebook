# Agent Harness 千千万，这一个属于我

> - **原文标题**　*There are many agent harnesses, but this one is mine.*
> - **作者**　Earendil Operations `<rfc@earendil.com>`；Jakob，Earendil Founders Associate

*一个非工程师的笔记*

我不是工程师。在一家为那些对着黑色终端窗口敲字的程序员开发 Agent Harness 软件的公司里，这件事以前让我觉得应该小声说出来。身边每个人都在交付代码，我则在写文档、做规划、与人交谈。这些工作当然有用，但我并没有真正使用我们制造的东西。

于是有一段时间，我像许多人面对 AI 时悄悄做的那样：跟着点头。我听过“Agent”“循环”“Harness”和“Extension”足够多次，已经能够在会议里很像样地点头。别人都觉得 TUI 是常识时，我却在偷偷搜索它是什么；等我终于弄懂，大家早已谈起 API，我又回到了起点。借用我们《[什么是 Agent Harness？](/translations/what-is-a-harness)》中的一句话，我就是那个“因为不好意思而没有问出口”的人。

后来，我不再只是点头，而是做了一件更好的事：打开 Pi，开始提问。

Harness 并不在意你不会编程。打开它，用自然语言写下想要什么，它就开始工作。我原以为总会碰到一个关卡，因为自己懂得不够而卡住。但实际情况是，我只需要继续写下自己的需求。第一次让它阅读一份又长又难看的 PDF，并告诉我真正需要知道的三件事时，它就那么完成了。我感到一阵小小的、甚至有点滑稽的力量涌上来。

在令人望而生畏的外表之下，Harness 只是一种工具：把“我希望有人能替我做这件事”，变成“已经完成”。

## 把它变成我的

Pi 最让我喜欢的用途与软件开发毫无关系。每天早晨，它会读一遍我的收件箱和会议记录，找出我真正答应别人要做的事情，然后生成一份干净的待办清单：一组是我欠别人的，另一组是我正在等待别人回复的。

我没有雇人，也没有先去学编程。我只描述了一次这份工作，它就变成在我电脑上运行的小流程，而且完全按照我的思维方式塑造。

偶尔好奇心上来、想打开引擎盖看看时，Pi 又是一位非常耐心的老师。有一次，我让它指导我编写 Google Apps Script。它一步一步带我走完整个过程，就像请一位最慷慨的软件工程师同事来讲解：使用平实的语言，而且不会让你觉得自己很笨。

在某次解释进行到一半时，代码不再那么令人害怕。现在，我也会自己制作东西了。它们并不惊天动地，主要是一些真正能让工作和生活轻松一点的小工具：制作个性化数字邀请函、管理邮件互动指标，以及用电子表格自动化整理数据。

也就是在这时，那句标语终于对我有了意义：Agent Harness 千千万，但这一个是你的。

过去，我把它理解成写给工程师的话——写给那些会打开引擎盖、重新接线的人。现在我对“你的”有了不同理解。它不是说这个工具一定由你亲手创造，而是说，无论你是谁，都可以让它适应自己的生活。

我让自己的 Pi 围绕杂乱的收件箱运转。另一个人也许会让它围绕课程规划、研究或小企业记账运转。

## 为什么这件事比我的待办清单更重要

Pi 免费、开源，而且运行在我自己的笔记本电脑上。过去，这听起来只是一个技术脚注。现在我明白它为什么重要：我可以按照自己的工作方式塑造它。

真正让我感到不同的是，Pi 能查看自己的代码，解释它如何工作，再帮助我修改它。仿佛这个工具能够教我怎样重新打造工具本身。原文写作时，Pi 用户已经相互分享了 5,000 多个 Extension，把自己构建的工作流自由地交给其他人。

关于 AI 的许多讨论，都集中在这项技术会对我们做什么。坐在我的位置上，真正有意思的变化是：我不再需要等待某个技术人员替我做出想要的工具。

我仍然不是工程师，但已经不会压低声音说这件事了。原来，拥有自己的工具并不要求你先成为工程师；你只需要有足够的好奇心去提问，也有足够的勇气继续走下去。

——Jakob，Earendil Founders Associate
