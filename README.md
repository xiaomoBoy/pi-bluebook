# Pi 学习蓝皮书

面向初学者的非官方 Pi 学习路径：从第一次真实任务开始，逐步形成可验证、可复用的 Agent 工作流。

当前仓库处于最小预览阶段，只包含首页、一个示范章节和推文资料库样稿。

在线预览：[pi.xiaomovps.com](https://pi.xiaomovps.com)

文章从原始材料到发布的分工与验收方式见 [EDITORIAL_WORKFLOW.md](./EDITORIAL_WORKFLOW.md)。

## 本地预览

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```
